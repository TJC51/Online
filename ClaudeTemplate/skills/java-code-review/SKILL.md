# Java 代码审查

对指定 Java 文件进行全面审查，输出分级报告。

## 审查维度

### 1. 正确性
- [ ] 逻辑是否正确处理所有条件分支？
- [ ] null 检查是否完备？
- [ ] 数组/集合越界风险？
- [ ] 并发场景的线程安全性？

### 2. 安全性
- [ ] SQL/命令注入风险？
- [ ] 敏感信息泄露（日志中的密码、Token）？
- [ ] 输入校验是否充分？
- [ ] 文件路径遍历风险？

### 3. 性能
- [ ] N+1 查询问题？
- [ ] 不必要的对象创建？
- [ ] 字符串拼接是否用了 StringBuilder？
- [ ] 资源是否正确关闭（try-with-resources）？

### 4. 可维护性
- [ ] 命名是否清晰表意？
- [ ] 方法是否过长（> 30 行）？
- [ ] 是否有重复代码？
- [ ] 注释是否解释"为什么"？
- [ ] 是否符合 SOLID 原则？

## 输出格式

```markdown
## Code Review: {文件名}

### 🔴 严重问题
- **行**: X
- **问题**: 描述
- **修复**: 代码建议

### 🟡 改进建议
- **行**: Y
- **问题**: 描述
- **建议**: 优化方案

### 🟢 亮点
- 做得好的地方

### 总结
严重: X | 建议: Y | 亮点: Z
```
